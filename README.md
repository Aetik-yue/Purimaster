# Purimaster 净化大师

> 轻量、干净、删得放心的 Windows 磁盘清理工具。

Purimaster 是一款开源（MIT）的 Windows 磁盘清理工具，基于 Tauri 2 与 Rust 构建。
没有广告、没有捆绑、没有遥测；所有删除默认可恢复，动手之前可以先预演。

## 功能一览

应用分三个页签，各自对应一类诉求：

### 🗺️ 空间分析 — 看清空间去哪了

- 按目录扫描磁盘占用，实时显示进度（文件数、字节数、已用时长），随时可取消
- 常用盘符一键直达，目录树逐层下钻，大文件一眼定位
- 在目录树里直接勾选文件/文件夹手动删除——走的是与规则清理完全相同的
  安全删除管线（见下方[安全设计](#安全设计)）

### 🧹 垃圾清理 — 一键扫出可清理量

- 内置 **18 条**清理规则，覆盖临时文件、浏览器缓存、应用缓存、
  开发工具缓存、系统残留、崩溃转储六大类
- 打开即扫，首屏即见可清理量；支持**预演**——只做安全检查不真删，确认无误再动手
- **定向清理**：对任意指定目录执行与规则清理相同的安全管线
- 对近期文件网开一面：多数临时/缓存规则只清理修改时间早于 24 小时（部分规则 7 天）的文件，
  避免误删正在使用的缓存
- 清理完成后出具报告：每条规则删了什么、释放了多少空间

### 📦 软件卸载 — 卸得干净

- 列出本机已安装软件，支持批量勾选卸载，逐项展示进度与结果
- 卸载完成后自动扫描残留（残留目录与注册表键），逐项勾选清除

## 安全设计

清理软件最大的风险是删错文件。Purimaster 把安全放在功能前面：

- **回收站优先** — 默认删除方式是移入回收站，随时可恢复；
  永久删除不可恢复，必须经过界面二次确认。
- **预演（dry-run）** — 各清理入口均可先"只做安全检查、不执行删除"，
  预演通过后再正式清理。
- **逐文件八步校验** — 全项目只允许一个模块执行删除，每个文件动手前依次通过八道检查：
  目标根不是链接/联接点 → 确认是普通文件 → 重过系统关键路径保护 →
  真实路径必须位于目标根之下 → 不命中保护路径 → 回收站卷预检 →
  预演到此为止 → 删除前最后复检原路径未变化，然后才删除。
- **注册表守卫** — 注册表删除入口带硬编码拒绝清单：只放行 `Software\` 之下、
  非 Classes、非 `Microsoft` 子树（程序自己的卸载键除外）。
  这条守卫不受任何数据或参数影响——即使调用方传错，系统关键区域也删不掉。
- **规则即数据（18 条）** — 清理规则是一份 TOML 数据文件（`rules/junk.toml`），
  调整规则无需重新编译；而系统关键路径保护硬编码在 Rust 代码里，
  规则文件即使被篡改，也碰不到系统与个人文件。
- **关窗保护** — 有扫描或清理任务进行中时关闭窗口会先弹确认，避免删除中断后拿不到报告。

## 下载安装

前往本仓库的 [Releases](../../releases) 页面，下载最新版本的安装包
（`.exe` 安装程序，NSIS 打包），双击安装即可。

- 系统要求：Windows 10 / 11（依赖系统自带的 WebView2 运行时）

## 从源码构建

前置依赖：Rust stable、Node.js 与 pnpm、Windows 10/11。

```bash
git clone <本仓库地址>
cd purimaster
pnpm install
pnpm tauri dev      # 开发调试
pnpm tauri build    # 产出 NSIS 安装包
```

提交前的质量门禁（与 CI 执行内容一致）：

```bash
cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
pnpm lint && pnpm build
```
