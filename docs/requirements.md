# Purimaster 需求文档

- **版本**: v0.3
- **日期**: 2026-11-06
- **状态**: 已评审（项目启动会）

---

## 1. 背景与目标

Windows 上的磁盘清理工具长期被两类产品占据：一类是广告、捆绑、弹窗不断的"全家桶"（以某些国产管家类软件为代表），一类是功能强大但界面陈旧、对普通用户不友好的专业工具。用户缺少一个**轻量、干净、删得放心**的选择。

Purimaster 的目标：做一个开源的 Windows 磁盘清理工具，把"**安全**"和"**快**"作为第一优先级，参考优秀工具的精华（Geek 的极简、WizTree 的快、Czkawka 的准），去掉它们的糟粕（臃肿、不可控、来路不明的"优化"）。

**产品三原则**：

1. **安全第一** — 任何删除操作默认可恢复，危险操作必须显式确认
2. **只做清理** — 不做"优化""加速""修复注册表"这类玄学功能
3. **零骚扰** — 无广告、无捆绑、无遥测、无开机自启（除非用户开启）

## 2. 目标用户

- 主要：有"C 盘又满了"困扰的普通 Windows 用户
- 次要：希望了解磁盘空间去向的进阶用户 / 开发者

## 3. MVP 功能需求（v0.1）

### 3.1 垃圾文件扫描清理

| 项 | 说明 |
|----|------|
| 描述 | 扫描常见垃圾文件位置，分类展示，用户勾选后清理 |
| 扫描范围（MVP） | 系统/用户 Temp 目录、回收站、浏览器缓存（Chromium 系）、Windows 更新残留、缩略图缓存、崩溃转储 |
| 规则 | 清理规则以**数据文件**（TOML）定义，与代码分离，见 [ADR-0002](docs/decisions/0002-rules-as-data.md) |
| 删除策略 | 默认移入回收站；永久删除需二次确认；系统关键路径默认排除且不可扫描 |
| 验收 | 扫描结果可按类别分组展示；清理前显示总可释放空间；支持 dry-run 预览 |

### 3.2 大文件查找

| 项 | 说明 |
|----|------|
| 描述 | 对全盘或指定目录扫描，按文件大小列出 Top-N |
| 交互 | 支持按大小/日期排序、按类型过滤、直接定位到所在目录 |
| 验收 | 100 万文件级别的卷可在合理时间（< 60s，SSD）完成扫描；扫描过程可取消 |

### 3.3 重复文件查找

| 项 | 说明 |
|----|------|
| 描述 | 指定目录内基于**内容**查找重复文件 |
| 算法 | 大小预筛 → 首尾分块哈希 → 全量哈希（三级流水，避免大文件全量读） |
| 交互 | 重复组展示；支持"保留最旧/最新/手动指定"；清理走统一删除策略 |
| 验收 | 不误报（哈希碰撞除外，使用 128 位以上哈希） |

### 3.4 磁盘空间可视化分析

| 项 | 说明 |
|----|------|
| 描述 | 按目录聚合的空间占用视图（Treemap / 条形图），下钻浏览 |
| 验收 | 可从盘符逐级下钻到具体文件；扫描一次后各视图复用同一份索引数据 |

### 3.5 软件卸载（v0.3 新增，见 [ADR-0004](decisions/0004-uninstaller.md)）

| 项 | 说明 |
|----|------|
| 描述 | 枚举已安装软件（注册表卸载键），多选后逐个启动**官方卸载器**；完成后扫描文件与注册表残留，用户逐项确认清除 |
| 边界 | 这是"卸载残留移除"，不是注册表"清理/优化"——注册表删除受硬编码守卫约束（仅该软件自己的键与 `Software\<名称>` 精确匹配），与 §7 Non-Goal 不冲突 |
| 安全 | 不使用静默卸载参数；残留逐项可见可选；UWP/Store 应用暂不支持（记为已知限制） |
| 验收 | 列表与"设置-应用"一致；卸载后残留可见可清；受保护注册表区域无法被删 |

## 4. 非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | 目录遍历多线程并行；空闲内存占用 < 150 MB |
| 体积 | 安装包 < 10 MB（Tauri 优势，需守住） |
| 隐私 | 零遥测，不联网（MVP 阶段完全离线可用） |
| 平台 | 仅 Windows 10/11 x64 |
| 语言 | 中文优先，架构上预留 i18n |
| 安全 | 不申请不必要的权限；需要管理员权限的操作必须明确提示原因 |

## 5. 竞品分析

| 产品 | 借鉴（精华） | 避免（糟粕） |
|------|------------|------------|
| Geek Uninstaller | 极简单文件、零安装、界面克制 | 仅覆盖卸载场景，清理能力弱 |
| WizTree | MFT 直读带来的极快全盘扫描 | 闭源、商业化 |
| Czkawka | Rust 实现、多线程、精确去重算法 | 界面偏工程师审美，普通用户门槛高 |
| SpaceSniffer | Treemap 可视化直观 | 扫描慢、UI 老旧 |
| BleachBit | 开源、规则透明 | 界面不友好，Windows 体验一般 |
| CCleaner | 品类标杆、规则积累丰富 | 捆绑、遥测、注册表清理争议、曾被植入恶意更新 |

## 6. 版本规划

| 版本 | 主题 | 内容 |
|------|------|------|
| v0.1 | MVP | 上述四大功能 + 安全删除框架 + 清理规则引擎 |
| v0.2 | 打磨 | 扫描性能（USN/MFT 加速调研）、i18n、自动更新 |
| v1.0 | 发布 | 安装包、签名、官网、文档站 |

后续候选项（不在 MVP）：启动项管理、文件粉碎、相同图片/音乐查找（参考 Czkawka）。

## 7. 明确不做（Non-Goals）

- ❌ 注册表"清理/优化"（收益存疑、风险高，CCleaner 教训）
- ❌ "内存加速""开机加速"等伪优化
- ❌ 任何形式的广告、推广位、弹窗
- ❌ 跨平台（macOS/Linux）——见 [ADR-0001](docs/decisions/0001-rust-tauri.md)，但 core crate 不写死 Windows
