# 开发日志 2026-11-04（九）：清理流程按主流清理软件心智重构

## 背景

用户反馈："现在的操作方式就不符合正常人的使用清理软件的逻辑，你进行全面改进一下"。结合日志复盘，旧交互有三个根本问题：

1. **结果永远看不到**：进页签自动扫描 → 用户切走 → 扫描被取消 → 缓存永远为空 → 下次又重扫（日志里 6+ 次"启动/已取消"循环，从未出现"完成"）
2. **操作路径太长**：找到行首小复选框 → 勾选 → 找到上方「清理选中」，三步无引导
3. **信息层级错位**：清理软件的主视觉应该是"能清多少 + 一个大按钮"，而不是技术细节列表

## 重构（主流清理软件的标准流程）

**打开 → 自动扫描 → 大数字 + 清单（安全项预勾选）→ 立即清理 → 报告**

- **后端结果缓存**：`junk_cache` 持久化最近一次扫描结果；**切页不再取消垃圾扫描**（只读、会完成、写入缓存）；重新进入页面按"会话缓存 → 后端缓存（标记历史结果）→ 自动扫描"取数，扫一次终身受用
- **主视觉区**：大字号"可清理空间 X"（随勾选实时变化）+ 一个大「立即清理」按钮
- **清单即勾选**：点击行 = 勾选/取消（不再抢走展开语义）；**低风险项默认勾选，中/高风险留白**（安全默认 + 用户知情）；「详情 ▾」单独展开目标/文件预览
- **确认弹窗带清单**：列出将清理的项目和大小，回收站默认、永久删除红色警告、试运行选项
- 移除了旧的 selection-bar / 一键清理全部 / 行内清理按钮三套重复入口

## 决策记录

- 勾选预选策略：只预勾 low；medium（Windows 更新缓存）与 high 需用户手动——与需求文档"安全第一"一致
- 垃圾扫描切页不取消：只读操作且写入后端缓存，取消只浪费已完成的工作
